# LMS Project — REST API для платформы онлайн-обучения

Бэкенд-сервер для LMS-системы на Django REST Framework.  
Позволяет управлять пользователями, курсами и уроками через JSON API.

---

## 📋 Функционал

- **Пользователи** — кастомная модель с авторизацией по email, полями `phone`, `city`, `avatar`
- **Курсы** — создание, просмотр, обновление, удаление (CRUD)
- **Уроки** — создание, просмотр, обновление, удаление (CRUD)
- **Связь** — один курс содержит много уроков (`ForeignKey`)
- **API** — JSON-ответы для SPA, мобильных приложений и внешних клиентов

---

## 🛠️ Технологии

- Python 3.10
- Django 6.1
- Django REST Framework
- Pillow (для изображений)
- Git / GitHub
